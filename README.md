# FORMA Fitness

A responsive, Apple-inspired fitness landing page built with plain HTML, CSS, and vanilla JavaScript.

## Features

- Minimal, editorial visual design with generous spacing and restrained colors
- Responsive layout for mobile, tablet, and desktop
- Sticky navigation and mobile menu
- Fitness program cards for strength, mobility, endurance, and recovery
- CSS-built dashboard preview and decorative program artwork
- Inline SVG icons and subtle hover/press feedback
- Scroll-triggered reveal motion and animated dashboard bars
- Accessible labels, status feedback, and reduced-motion support
- Client-side demo signup form with validation

## Run locally

No build tools or dependencies are required.

1. Extract the ZIP.
2. Open `index.html` in a modern browser.

For a more realistic local development server, run this from the project folder:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000`.

## Notes

- The hero image is loaded from Unsplash and Google Fonts are loaded remotely, so those elements require an internet connection.
- The signup form is a front-end demo. It does not send or store submissions. Connect it to your own API or form provider before production use.
- This is an original design inspired by Apple's minimalist design principles, not an Apple product or affiliated brand.
